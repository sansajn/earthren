OpenGL library C++ wrappers and helper abstractions.

This is not standalone library yet it lives within *earthren* project for now.

I'm heavilly inspired with my previous work from [ogltest](https://github.com/sansajn/ogltest/tree/master), but for *earthren* I want something else.

One of the key idea of *ogl* is that we do not want to porpagate OpenGL types (`GLxxx`) macros. We want to work as much as possible with language types to preserve look and feel of C++.
